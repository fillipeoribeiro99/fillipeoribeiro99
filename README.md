## 📌 Projetos em destaque

### 📊 Análise de Vendas e Performance Comercial

Projeto de Business Intelligence desenvolvido com Power BI, Power Query e DAX, utilizando uma base fictícia de vendas para analisar indicadores comerciais.

**Principais análises:**
- Faturamento e lucro ao longo do tempo.
- Desempenho por produto e categoria.
- Comparação de resultados entre regiões.
- Desempenho de vendedores e canais de venda.
- Margem de lucro e ticket médio.

**Tecnologias:** Power BI, Power Query, DAX e CSV.

[![Acessar projeto](https://img.shields.io/badge/Visualizar_projeto-181717?style=for-the-badge&logo=github)](https://github.com/fillipeoribeiro99/analise-vendas-power-bi)

### 🌱 Eco Tech Entregas — Aplicação de Delivery

Aplicação voltada à proposta de entregas sustentáveis, com produtos naturais e funcionalidades para facilitar a experiência de compra.

O projeto integra backend com Spring Boot, banco de dados MySQL e interface desenvolvida com tecnologias web. Possui funcionalidades de cadastro, autenticação e gerenciamento de carrinho de compras.

**Tecnologias:** Java, Spring Boot, MySQL, HTML, CSS e JavaScript.
